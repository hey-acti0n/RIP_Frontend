### 7. Настройка HTTPS

**Цель:** Показать настройку HTTPS для безопасного соединения

**Шаги для настройки HTTPS:**

#### Вариант 1: Настройка через Nginx (рекомендуется для продакшена)

1. **Установите SSL сертификат:**
   - Используйте Let's Encrypt (бесплатный) или собственный сертификат
   - Для локальной разработки можно использовать self-signed сертификат

2. **Настройте Nginx:**
   - Откройте `nginx.conf` в проекте
   - Добавьте конфигурацию для HTTPS:
   ```nginx
   server {
       listen 443 ssl;
       server_name your-domain.com;
       
       ssl_certificate /path/to/certificate.crt;
       ssl_certificate_key /path/to/private.key;
       
       location / {
           root /path/to/dist;
           try_files $uri $uri/ /index.html;
       }
   }
   
   server {
       listen 80;
       server_name your-domain.com;
       return 301 https://$server_name$request_uri;
   }
   ```

3. **Обновите конфигурацию приложения:**
   - В `target_config.ts` измените адреса на HTTPS:
   ```typescript
   export const api_proxy_addr = "https://192.168.1.225:8080"
   export const img_proxy_addr = "https://192.168.1.225:9000"
   ```

4. **Обновите Tauri capabilities:**
   - В `src-tauri/capabilities/default.json` добавьте HTTPS URL:
   ```json
   {
     "url": "https://192.168.1.225:8080"
   },
   {
     "url": "https://192.168.1.225:9000"
   }
   ```

#### Вариант 2: Настройка через бэкенд (Go)

1. **Настройте HTTPS в бэкенде:**
   - Используйте TLS сертификаты в Go приложении
   - Настройте сервер на прослушивание порта 443

2. **Для разработки (self-signed сертификат):**
   ```bash
   # Генерация self-signed сертификата
   openssl req -x509 -newkey rsa:4096 -keyout key.pem -out cert.pem -days 365 -nodes
   ```

**Что показать:**
- Приложение работает по HTTPS
- В браузере/Tauri показывается замочек (для валидного сертификата)
- Запросы идут через защищенное соединение

**Технические детали:**
- HTTPS требует SSL/TLS сертификат
- Для локальной разработки можно использовать self-signed сертификат
- Для продакшена рекомендуется Let's Encrypt
- После настройки HTTPS нужно обновить все URL в конфигурации

**Файлы для настройки:**
- `nginx.conf` - конфигурация Nginx
- `src/config/target_config.ts` - адреса API
- `src-tauri/capabilities/default.json` - разрешения Tauri

**Примечание:**
- Если используется self-signed сертификат, браузер/Tauri может показывать предупреждение
- Для продакшена обязательно используйте валидный сертификат от доверенного CA

### Возможные проблемы и решения

**Проблема:** PWA не устанавливается на телефоне

- **Решение:** Проверьте, что Redux store правильно инициализирован в `App.tsx`

**Проблема:** Tauri не подключается к бэкенду
- **Решение:** 
  - Проверьте IP адрес в `target_config.ts`
  - Убедитесь, что capabilities разрешают запросы к нужному IP
  - Пересоберите Tauri приложение после изменения capabilities

**Проблема:** Изменения в БД не отображаются
- **Решение:** Обновите страницу в приложении (F5)
