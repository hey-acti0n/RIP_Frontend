# Настройка HTTPS в Tauri приложении

## Текущая конфигурация

HTTPS поддержка уже настроена в Tauri приложении. Для включения HTTPS выполните следующие шаги:

## Шаги для включения HTTPS

### 1. Обновите конфигурацию

Откройте файл `src/config/target_config.ts` и измените:

```typescript
const use_https = true  // Измените с false на true
```

### 2. Настройте SSL сертификаты на backend

Для работы HTTPS нужны SSL сертификаты на сервере. Есть несколько вариантов:

#### Вариант A: Самоподписанный сертификат (для разработки)

```bash
# Создайте самоподписанный сертификат
openssl req -x509 -newkey rsa:4096 -nodes \
  -keyout key.pem -out cert.pem \
  -days 365 -subj "/CN=192.168.1.227"
```

#### Вариант B: Использование mkcert (рекомендуется для разработки)

```bash
# Установите mkcert
brew install mkcert  # macOS
# или
# apt install mkcert  # Linux

# Создайте локальный CA
mkcert -install

# Создайте сертификат для вашего IP
mkcert 192.168.1.227 localhost 127.0.0.1
```

### 3. Настройте backend для HTTPS

Обновите backend сервер для поддержки HTTPS (зависит от вашего backend фреймворка).

### 4. Настройте MinIO для HTTPS

MinIO также должен поддерживать HTTPS. Обновите конфигурацию MinIO.

### 5. Перезапустите Tauri

После настройки сертификатов перезапустите Tauri приложение:

```bash
npm run tauri dev
```

## Текущие разрешения

В файле `src-tauri/capabilities/default.json` уже добавлены разрешения для:
- `https://192.168.1.227:8080` (API)
- `https://192.168.1.227:9000` (MinIO)
- `https://localhost:8080` и `https://localhost:9000` (для совместимости)

## Важные замечания

1. **Для разработки**: Обычно используется HTTP, так как настройка HTTPS требует дополнительных шагов
2. **Для production**: Обязательно используйте HTTPS с валидными сертификатами
3. **Самоподписанные сертификаты**: Tauri может показать предупреждение о недоверенном сертификате
4. **CORS**: Убедитесь, что backend настроен для работы с HTTPS

## Отключение HTTPS

Если нужно вернуться к HTTP, просто установите:

```typescript
const use_https = false
```

в файле `src/config/target_config.ts`
