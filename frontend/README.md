# UltraRezina Frontend

React приложение для работы с материалами виброизоляции.

## Технологии

- React 18
- TypeScript
- React Router DOM
- React Bootstrap
- Vite

## Структура проекта

```
src/
├── components/          # Переиспользуемые компоненты
│   ├── Navbar.tsx      # Навигационная панель
│   ├── Breadcrumbs.tsx # Навигационная цепочка
│   ├── MaterialCard.tsx # Карточка материала
│   └── MaterialFilters.tsx # Фильтры материалов
├── pages/              # Страницы приложения
│   ├── HomePage.tsx    # Главная страница
│   ├── MaterialsPage.tsx # Список материалов
│   └── MaterialDetailPage.tsx # Детальная страница материала
├── services/           # API сервисы
│   └── api.ts         # Сервис для работы с API
├── types/             # TypeScript типы
│   └── api.ts        # Типы для API
├── styles/            # Стили
│   └── App.css       # Основные стили
└── utils/            # Утилиты
```

## Функциональность

### Главная страница (/)
- Статическое описание компании
- Информация об услугах
- Навигация к списку материалов

### Страница материалов (/materials)
- Список всех материалов с карточками
- Фильтрация по:
  - Названию
  - Типу материала
  - Толщине (диапазон)
  - Плотности (диапазон)
- Пагинация
- Поиск в реальном времени

### Детальная страница материала (/materials/:id)
- Подробная информация о материале
- Характеристики
- Описание
- Изображение (с дефолтным при отсутствии)

## API интеграция

Приложение подключается к Go API серверу через проксирование:
- Базовый URL: `/api/v1`
- Прокси настроен в `vite.config.ts`
- При недоступности API используются mock данные

### Endpoints:
- `GET /api/v1/materials` - список материалов с фильтрацией
- `GET /api/v1/materials/:id` - детальная информация о материале

## Запуск

1. Установка зависимостей:
```bash
npm install
```

2. Запуск в режиме разработки:
```bash
npm run dev
```

3. Сборка для продакшена:
```bash
npm run build
```

## Настройка

### Проксирование API
Настроено в `vite.config.ts`:
```typescript
server: {
  proxy: {
    "/api": {
      target: "http://localhost:8080",
      changeOrigin: true,
    },
  },
}
```

### Стили
Используется темная тема в стиле оригинального дизайна:
- Цветовая схема: темно-серые тона
- Градиентный фон
- Карточки с закругленными углами
- Адаптивный дизайн

## Особенности

1. **Mock данные**: При недоступности API автоматически используются mock данные
2. **Дефолтные изображения**: Для материалов без изображения показывается заглушка
3. **Адаптивность**: Полностью адаптивный дизайн для мобильных устройств
4. **TypeScript**: Полная типизация для безопасности кода
5. **Breadcrumbs**: Навигационная цепочка на всех страницах
6. **Фильтрация**: Продвинутая система фильтрации с сохранением состояния
